# Exercício 1 - Rota POST `/mensagem`

Projeto desenvolvido em Node.js com Express e TypeScript para praticar a criação de rotas do tipo `POST`, leitura do corpo da requisição (`req.body`), tratamento de erros e retorno de status HTTP.

## 📋 Descrição

A aplicação disponibiliza um servidor HTTP na porta `8081` contendo a rota `POST /mensagem`, que recebe três dados via JSON (`nome`, `idade` e `timeFavorito`), valida se todos foram informados e retorna uma mensagem personalizada.

## 🚀 Tecnologias Utilizadas

* [Node.js](https://nodejs.org/)
* [Express.js](https://expressjs.com/)
* [TypeScript](https://www.typescriptlang.org/)
